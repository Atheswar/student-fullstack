# Student Management System

A full-stack student management application built using Spring Boot, React, and MySQL.

## Technologies Used

- Java and Spring Boot
- React and Vite
- MySQL
- Axios
- Git and GitHub

## Features

- View all students
- Add student records
- Search students by name
- Delete student records
- Validate student details
- REST API integration

## Run the Backend

1. Open the backend project in Eclipse.
2. Configure MySQL credentials locally.
3. Run the Spring Boot application.
4. Backend URL: http://localhost:8080

## Run the Frontend

1. Open a terminal in the frontend project folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite, usually http://localhost:5173.

## Security

Do not commit real database passwords, API keys, or secret environment files.
