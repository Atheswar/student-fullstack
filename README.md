\# Student Management System



A full-stack application built using Spring Boot, React, and MySQL.



\## Technologies

\- Java

\- Spring Boot

\- React and Vite

\- MySQL

\- Axios

\- Git and GitHub



\## Features

\- View student records

\- Add students

\- Search students by name

\- Delete students

\- Validate student details

\- REST API integration



\## Run Backend

1\. Open the backend project in Eclipse.

2\. Configure MySQL credentials locally.

3\. Run the Spring Boot application on port 8080.



\## Run Frontend

1\. Open the frontend project folder in VS Code.

2\. Run `npm install`.

3\. Run `npm run dev`.

4\. Open the URL shown by Vite, usually http://localhost:5173.



\## Security

Never commit real database passwords or secret environment files.
